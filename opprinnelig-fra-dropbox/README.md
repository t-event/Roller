# Opprinnelige filer fra Dropbox

Dette er de originale 306 filene fra Dropbox-mappen "NewNewNew Roller",
akkurat slik Ørjan hadde dem, lastet opp av Mathias 2026-09-10. Ingenting
her er endret, rettet eller ryddet i — det er nøyaktig det spillet var før
noe av arbeidet i `TIL-ORJAN.md` startet.

Samme innhold som denne mappen ble faktisk selve utgangspunktet for hele
`t-event/Roller`-repoet i utgangspunktet (se første oppføring i
`../TIL-ORJAN.md`, datert 2026-09-09), så det ligger allerede i git-
historikken til dette repoet også, om noen foretrekker å sjekke ut den
aller første committen fremfor å bla i denne mappen. Denne mappen finnes
i tillegg for at Ørjan skal kunne bla i de opprinnelige filene direkte på
GitHub uten å måtte grave i git-historikk.

Alt som faktisk brukes i spillet i dag ligger i `../scenes/` og `../lib/`
(se "Mappestruktur" i `../KODEBASE.md`), ikke her.
